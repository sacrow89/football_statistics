PREMIER LEAGUE FIXTURE INGESTION - QUICK REFERENCE

Run these commands in PowerShell from the root of the football_statistics
repository. The first command installs the Python packages required by the
notebook runner. You generally only need to run it the first time, or after
requirements.txt changes.

    python -m pip install -r requirements.txt

Run the fixture notebook using its YAML job configuration:

    python scripts\run_notebook.py --config config\jobs\fixtures\premier_league_fixtures.yml

The YAML configuration tells the runner which notebook and Jupyter kernel to
use, and sets the timeout for each notebook cell. The runner executes the
notebook locally and reports an error if execution fails.

Before running, make sure API_FOOTBALL_KEY is set in the environment inherited
by PowerShell. The notebook reads the key from that environment variable; do
not paste the key into the notebook, YAML file, or this reference file.

The notebook calls API-Football directly, so it must run on a computer or
runner that can reach that API. It is not intended to run as a Databricks job.
By default it fetches Premier League seasons 2026, 2025, 2024, and 2023. Set
FIXTURE_SEASONS to a comma-separated list (for example, 2026) to choose seasons.
Each raw API response is saved in its own timestamped folder under that season:

    data\bronze\fixtures\league_id=39\season=YYYY

The local YAML setup runs the job on demand. The root azure-pipelines.yml
defines a separate Azure Pipelines schedule for Mondays at 06:00 UTC. It uses
a Windows self-hosted agent, refreshes season 2026, and requires an
API_FOOTBALL_KEY secret pipeline variable. See README.md in this folder for
the Azure DevOps setup steps. The agent account needs Python and write access
to BRONZE_DATA_ROOT. Bronze JSON files are ignored by Git.

To use the existing agent manually, open a separate PowerShell window and run:

    cd C:\Users\Sam\OneDrive\Documents\devops_agent\vsts-agent-win-x64-4.272.0
    .\run.cmd

Leave this window open while Azure Pipelines runs. The agent is registered in
the Default pool as sam-pc. Stop it with Ctrl+C after the pipeline finishes.
